# Biobizz Calculator

BioBizz All-Mix Dünger Rechner – berechnet die Düngermenge (ml) je nach Woche und Wassermenge.

**Live:** https://vsvito420.github.io/biobizz/

## Funktionen

- Düngermenge pro Woche und Wassermenge (Liter) berechnen
- Gieß-Tagebuch: Gießen mit einem Klick eintragen, inkl. Datum, Mischung und Notiz
- Mehrere Pflanzen, optional mit Blütebeginn (Woche wird automatisch berechnet)
- Übersicht der letzten 28 Tage, „zuletzt gegossen vor X Tagen“
- Daten bleiben lokal im Browser (localStorage), Backup als JSON, Export als CSV

Reines HTML/CSS/JS, keine Build-Schritte. Lokal starten: `python3 -m http.server` und `http://localhost:8000` öffnen.
